# 诈识图谱 · 特征词典 v1 · 维度：利益诱惑（G / Bait / Gain）
#==========================================================================
#
# 【这个维度是什么】
#   给你一个"不参与就亏了"的理由。这一维度最容易被关键词表抓到，
#   也最容易被正常人误伤——"返利""红包"在日常营销里到处都是。
#   所以判分不靠单个词，靠"金额承诺 + 低门槛 + 必须动作"三件套同时出现。
#   注意：本维度的"理赔/赔付"专指快递、商品类的超额赔付承诺，是引流诱饵。
#
# 【子类】
#   G1  收益承诺 —— 给你算得出来的钱（20 词）
#   G2  稀缺竞争 —— 别人在抢，你不抢就没了（10 词）
#   G3  低门槛 —— 你不需要任何条件就能参与（14 词）
#   G4  信贷额度 —— 用小钱撬大钱（16 词）
#
# 【词条格式】
#   词条 | 子类 | 权重 | 判定含义 | 本库命中条数
#   # 开头为注释行，加载时跳过；空行忽略
#
# 【本库依据 —— 每个词都在 200 条真实案例里查过】
#   60 个词中 40 个在案例库中实际出现，20 个为语义扩展词
#   该维度至少命中 1 词的案例：82 / 200（41%）
#   三维并集覆盖：183 / 200（92%）
#   归一化基准 CAP = 4（本维度 200 条案例原始分的 p90）
#
#   【语义扩展词】（本库 0 命中，未经数据验证，v2 需回测）：
#     返现、高回报、翻倍、限量、秒杀、内部渠道、特批、零投入、无需经验、动动手指、低门槛、无门槛、小额、免费、白送、免担保、低息、免息、提额、秒批
#
#   词表来源：先用 200 条案例做 n-gram 文档频率挖掘，再人工归类。
#   命中 0 条 ≠ 无用——案例平均仅 85 字，短文本天然覆盖稀。这部分词
#   在 D3–D5 标注阶段用新样本回测，未验证前保留原权重但会被标注为扩展词。
#

# 易混淆反例（做误报分析时对照看）
#--------------------------------------------------------------------------
# （正常）双十一 0 元购，限时秒杀，先到先得
# （正常）新用户注册立返 20 元红包
# （正常）学生凭学生证免费领礼品
# （正常）本店返利 5%，满 300 减 30
#
# 共同点：G1/G2 命中密集，但 D1 指向的是正常商家收款，D4 为 0。
# 区分点不在"有没有诱惑"，而在"是否要求脱离平台、索要验证码、要求保密"。
# 注意 "0元" 本库命中 20 条（全库最高频），但权重只给 2——因为它在正常
# 电商里同样高频，判别力来自"谁发的"而不是"这个词"。同理"返利""红包""免费"。

#--------------------------------------------------------------------------
# 计分规则
#--------------------------------------------------------------------------
# 【权重】
#   3 = 高危词。单独出现即显著提险，正常人际沟通中几乎不出现
#   2 = 强信号。诈骗语境高频，正常语境偶见，需结合同维度其他词
#   1 = 弱信号。单用无判别力，必须与其他维度共现才计分
#
# 【匹配】
#   最长匹配优先：先匹配长词，命中后屏蔽该区间，避免短词重复计分。
#   例："无法提现"命中后，"无法""提现"不再单独计；"点击链接"命中后"链接"不计。
#
# 【计分】
#   维度原始分 raw = Σ 命中词权重（同词只计一次）
#   维度归一   x   = min(1, raw / CAP)
#     CAP_P = 6    CAP_G = 4    CAP_D = 6
#   总分       = 0.30*P + 0.30*G + 0.40*D
#
#   CAP 标定依据：取 200 条诈骗案例该维度原始分的 p90。
#   为什么不用"全词典权重和"做分母——一条消息平均只命中 2-4 个词，用权重和
#   （约 130-160）做分母会把所有案例压到 0.05 以下，彻底失去分辨力。这是
#   v1 踩过的坑，写在这里免得 v2 再踩一次。
#
# 【判级】
#   阻断级：命中以下任一词，跳过打分直接最高风险——
#           安全账户 / 屏幕共享 / 共享屏幕 / 不要报警 / 别挂电话 / 不要挂电话
#           这几个词没有正常用途，不需要看上下文。
#   高风险：D 维度命中 ≥2 个权重 3 的词
#           或 总分 ≥ 0.55 且 D 命中 ≥1 个权重 3 的词
#   中风险：总分 ≥ 0.30
#   低风险：其余
#
#   为什么不能只看总分：冒充熟人类只有 D 维度有信号（新号/垫/别跟），
#   P 和 G 都是 0，加权总分上不去，但三个权重 3 的 D 词同时出现已足够判高危。
#
# 【为什么 D 权重 0.40 最高】
#   P 和 G 都可以在正常消息里很高（截止日期、商家促销），
#   但 D 一旦指向转账/验证码/屏幕共享，损失不可逆。
#   误报的代价是打扰，漏报的代价是钱没了——按漏报优先调参。
#
# 【v1 实测结果（2026-10-18 回测）】
#   诈骗 200 条：阻断 5 / 高 22 / 中 87 / 低 86（高危+阻断占 14%）
#   正常 22 条：误报 3 条（14%），其中高风险 0 条
#   结论：高风险层零误报，中风险层有误报——这是有意的取舍。中风险的输出是
#   "这条需要核实"而不是"这是诈骗"，把判断权留给用户。
#   若把阈值降到 0.25，诈骗侧中风险覆盖可升至约 60%，但正常文本误报会升到
#   30% 左右；学生用户对误报极敏感，不建议。
#
# 【已知局限（v2 要解决）】
#   1. 单句判定召回偏低。200 条案例多为单句片段，仅 14% 落在高/阻断。
#      但真实演示是粘贴整段聊天，多句累积后分数显著上升（实测 0.22→0.90）。
#      这不是缺陷，是"必须看上下文"的证据，答辩时可以直接讲。
#   2. 关系伪装类（冒充熟人/领导）信号弱。这类骗局靠"关系变更 + 资金请求"
#      的组合，词汇特征本身不明显，v2 需要独立的"关系异常"规则（换号、只用
#      文字不接语音、拒绝视频）。
#   3. 词典对正常电商/银行短信有 14% 中风险误报，需配合发送方特征（号码、
#      是否有官方签名）做二次过滤。
